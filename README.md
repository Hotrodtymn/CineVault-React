# CineVault-React

## React movie discovery application

A React 19 movie-discovery interface with React Router navigation and external movie-data integration.

> **Project type:** Portfolio project. This README describes the checked-in source rather than promising production functionality.

## Getting started

Run `npm install` and `npm start`; use `npm run build` for a production bundle.

## Notes

[Live demo](https://cinevault-sage-alpha.vercel.app/). External API behavior depends on service availability and configuration.
